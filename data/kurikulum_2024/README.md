# Dataset Kurikulum 2024 PTI UB

Berkas CSV di folder ini diekstraksi dari dua dokumen resmi Program Studi S1 Pendidikan Teknologi Informasi,
Fakultas Ilmu Komputer, Universitas Brawijaya:

- *Deskripsi Mata Kuliah Prodi PTI UB 2024–2029 v1.0*;
- *Ringkasan Struktur Kurikulum Prodi PTI UB 2024–2029 v1.0*.

Isi dokumen (deskripsi mata kuliah, CPMK, Sub-CPMK, struktur kurikulum, dan aturan akademik) tetap menjadi hak
Program Studi. Dataset ini **tidak** termasuk lisensi MIT yang berlaku untuk kode program di repositori ini, dan
disertakan sebagai dataset sampel agar aplikasi dapat dijalankan. Penggunaan ulang di luar keperluan tersebut perlu
izin Program Studi PTI FILKOM UB.

Folder ini hanya dibaca oleh aplikasi; jangan diedit manual. Ketidaksesuaian antardokumen dan keputusan atasnya
tercatat di `19_catatan_inkonsistensi.csv`.
